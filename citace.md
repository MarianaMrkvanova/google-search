Při tvorbě projektu byl jako pomocný nástroj použit Microsoft Copilot v prostředí Visual Studio Code. Pomohl s návrhem a úpravami HTML a CSS stránek a s kontrolou formulářů pro vyhledávání Googlem. Výsledný kód byl následně zkontrolován a upraven.
